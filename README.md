# Custom Resolution

A small macOS app that adds a custom "looks like" resolution to a display, such as an iPad-shaped
**1554 × 1080** on a 4K TV, and switches between it and your previous resolution.

## What it does

- **Add Resolution:** pick an aspect ratio (or a preset) and a "looks like" height. The app writes a
  display override file to `/Library/Displays/Contents/Resources/Overrides/` (it asks for your
  administrator password), then offers to restart. The display's original file is backed up first,
  to `~/Library/Application Support/CustomResolution/Backups/`.
- **Switch:** toggles between the custom resolution and the one you were using before.
- **Restore Original:** puts back the backed-up file (or removes the override if there wasn't one)
  and offers to restart.
- **Install Shortcut:** copies **Switch Resolution** into `~/Applications`. Clicking it does the same
  toggle without opening the main app. Both apps share `~/Library/Application Support/CustomResolution/config.json`.

## Good to know

- System Settings > Displays only lists sizes with the display's own shape (16:9 on most TVs and
  monitors). A custom size with a different shape works, but you switch to it with this app or the
  shortcut, not from System Settings.
- macOS ignores custom Retina entries on recent Macs (seen on M4), but it accepts a standard entry at
  double size and creates the Retina version itself. The app writes both kinds, so it works either way.
- M4 and M5 Macs limit Retina modes on external displays to 6720 pixels wide (3360 points).
- A major macOS update can reset the override folder. If the custom size disappears, add it again.

## Sharing it

Run `Scripts/export.sh` to build `dist/Custom-Resolution-<version>.dmg` and `.zip`.

By default the app is signed ad hoc, so the first time someone opens it macOS says it can't verify the
developer. They can open it anyway from **System Settings > Privacy & Security > Open Anyway**.

To avoid that warning, sign with a **Developer ID Application** certificate and notarize:

```sh
xcrun notarytool store-credentials custom-resolution   # one time; asks for your Apple ID and an app-specific password
SIGN_IDENTITY="Developer ID Application: Your Name (TEAMID)" NOTARY_PROFILE=custom-resolution Scripts/export.sh
```

The app writes to `/Library`, so it can't be sandboxed or sold on the Mac App Store.

## Developing

The Xcode project is generated with [XcodeGen](https://github.com/yonaskolb/XcodeGen) from `project.yml`.
After adding or removing files, run `xcodegen generate`. Icons are generated by `swift Scripts/make-icons.swift`.

Run the tests with:

```sh
xcodebuild test -project CustomResolution.xcodeproj -scheme CustomResolution -destination 'platform=macOS'
```
